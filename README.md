# PP-Encuestas

Proyecto de investigación en elq ue trabaje desarrollado en R para la descarga, limpieza y procesamiento de bases de datos de encuestas institucionales.

## Habilidades utilizadas

- R
- Manipulación de datos
- Automatización de procesos
- Limpieza y transformación de datos
- Programación reproducible

## Descripción

El proyecto automatiza la obtención y procesamiento de bases de datos de encuestas públicas, generando un flujo de trabajo reproducible para el análisis de información estadística.

## Archivos

- Main_script.R: script principal.
- Script Encuestas.R: funciones y procedimientos para el procesamiento de datos.
